# Start direkt aus VS Code

1. Repository-Ordner in VS Code öffnen.
2. `F5` drücken.
3. `Asset Editor starten` auswählen.

VS Code startet Vite über `npm.cmd`, wartet auf den lokalen Server und öffnet den Editor über den integrierten Edge-Debugger. Der feste Entwicklungsport ist `5174`, damit kein Konflikt mit Live Server auf `5173` entsteht.

Alternativ steht die Startkonfiguration `Asset Editor im Standardbrowser starten` bereit.

Weitere Aufgaben:

- `Terminal > Aufgabe ausführen > Asset Editor: Lint`
- `Terminal > Aufgabe ausführen > Asset Editor: Tests`
- `Terminal > Aufgabe ausführen > Asset Editor: Build`
- `Terminal > Aufgabe ausführen > Asset Editor: Komplett prüfen`

`Go Live` wird für dieses Vite-Projekt nicht verwendet.
